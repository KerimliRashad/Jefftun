# Zyng VPN — клиент для Windows и Linux

Простое приложение для компьютера/ноутбука: вставляешь ключ и подключаешься.
Как Happ, только для Windows. Внутри — официальное ядро **xray-core**.

## Как получить готовый .exe (без установки Python)

После пуша GitHub сам собирает программу:

1. Открой репозиторий → вкладка **Actions** → workflow **Build Zyng Desktop**
2. Дождись зелёной галочки (~2–3 мин)
3. Скачай **Zyng.exe** из раздела **Artifacts** внизу страницы
   (или со страницы **Releases** → `Zyng VPN`)

## Как пользоваться

1. Запусти **Zyng.exe**
2. Вставь свой ключ в поле:
   - `vless://...` (в т.ч. REALITY)
   - `vmess://...`
   - `trojan://...`
   - `ss://...`
   - или ссылку-подписку `https://...` → нажми «🔄 Загрузить подписку» → выбери сервер
3. Нажми **«Подключиться»** — статус станет зелёным «● Подключено»
4. Готово, весь трафик идёт через VPN
5. **«Отключиться»** — выключает VPN

Ключ можно сохранить кнопкой «💾 Сохранить ключ» — при следующем запуске подставится сам.

## Как это работает
- Приложение запускает `xray.exe` локально (SOCKS 10808 / HTTP 10809)
- Включает системный прокси Windows → все программы идут через VPN
- При отключении/закрытии прокси автоматически снимается

## Собрать самому (нужен Python)
Двойной клик по `build.bat` → готовый файл появится в `dist\Zyng.exe`.
