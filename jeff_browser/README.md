# Jeff Browser 🦈

Быстрый браузер на движке **Firefox** (сборка **r3dfox**, поддерживающая **Windows 7 / 8 / 8.1 / 10 / 11**).
Портативный — распакуй и запусти, ничего не устанавливая.

## Что внутри
- Поиск **Google** по умолчанию + Yandex, DuckDuckGo.
- Стартовая страница Jeff.
- Телеметрия выключена.

## Как это устроено (честно)
Jeff Browser — это **rebrand открытой сборки r3dfox** (форк Firefox для старых Windows), с нашим брендингом через `distribution/policies.json` и `autoconfig` (`mozilla.cfg`).
Полное переименование движка требует пересборки Firefox из исходников (часы компиляции) — здесь этого нет; брендинг сделан на уровне дистрибутива и лаунчера `Jeff.exe`.

Движок и лицензия — r3dfox / Mozilla Firefox (MPL 2.0). Спасибо команде **Eclipse-Community/r3dfox**.
