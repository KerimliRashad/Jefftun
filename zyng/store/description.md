## Description

```
Zyng — простой и быстрый VPN-клиент для тех, у кого уже есть ключ или подписка.

ПОДКЛЮЧЕНИЕ В ОДНО КАСАНИЕ
Одна большая кнопка на главном экране. Никакой регистрации, никаких учётных записей.

ПОДДЕРЖКА СОВРЕМЕННЫХ ПРОТОКОЛОВ
VLESS, VMESS, Trojan, Shadowsocks, Hysteria2, TUIC и SOCKS. Работают TLS, Reality и транспорты WebSocket, gRPC и HTTP.

ПОДПИСКИ
Добавь ссылку — список серверов появится сам и будет обновляться автоматически. Каждая подписка на отдельной вкладке: видно название, расход трафика и срок действия.

ВЫБОР БЫСТРОГО СЕРВЕРА
Проверка задержки до всех серверов в один тап. Видно, какой отвечает быстрее, ещё до подключения.

ПРИВАТНОСТЬ
Приложение не собирает данные. Ключи и настройки хранятся только на устройстве. Нет аналитики, рекламы и трекеров.

ЧТО НУЖНО ДЛЯ РАБОТЫ
Zyng — это клиент, а не сервис доступа. Для подключения нужен ключ или ссылка-подписка от вашего поставщика VPN.
```
