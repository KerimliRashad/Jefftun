# Публикация Zyng в App Store

Здесь лежат тексты и материалы для подачи. Шаги — по порядку.

---

## Шаг 1. Политика конфиденциальности — уже готова

Она живёт на сайте в `docs/privacy.html` и публикуется через GitHub Pages
на домен из `docs/CNAME`:

```
https://zyng.online/privacy.html
```

Этот адрес и вставляй в поле **Privacy Policy URL**.

Перед подачей открой ссылку в браузере и убедись, что страница грузится —
если Pages или DNS отвалились, App Store Connect не примет приложение.

---

## Шаг 2. Создай приложение в App Store Connect

1. Зайди на [appstoreconnect.apple.com](https://appstoreconnect.apple.com)
2. **My Apps** → **+** → **New App**
3. Заполни:

| Поле | Значение |
|---|---|
| Platforms | iOS |
| Name | Zyng |
| Primary Language | Russian |
| Bundle ID | `online.zyng.Zyng` |
| SKU | `zyng-ios-001` (любая строка, видна только тебе) |
| User Access | Full Access |

Если `online.zyng.Zyng` нет в списке Bundle ID — значит Xcode ещё не
зарегистрировал его. Собери приложение на устройстве один раз, и он появится.

---

## Шаг 3. Собери архив

В Xcode:

1. Вверху выбери **Any iOS Device (arm64)**
2. **Product** → **Archive**
3. Дождись окна **Organizer** (5–10 минут)
4. **Distribute App** → **App Store Connect** → **Upload** → далее по кнопкам

После загрузки сборка появится в App Store Connect минут через 15–30 — Apple
её обрабатывает. Пока ждёшь, заполняй описание.

---

## Шаг 4. Скриншоты

Нужны для двух размеров экрана. Проще всего снять в симуляторе:

- **6.9″** — iPhone 17 Pro Max
- **6.5″** — iPhone 17 Plus (или 15 Plus)

В симуляторе VPN не подключается, но интерфейс работает — для скриншотов
этого достаточно. Снимок: `⌘S` в симуляторе, файл ляжет на рабочий стол.

Сделай 3–5 кадров: главный экран, список серверов с подписками, окно
добавления ключа.

## Шаг 5. Описание

Возьми готовый текст из `description.md`.

## Шаг 6. App Privacy

**App Store Connect** → твоё приложение → **App Privacy** → **Get Started**

На вопрос «Do you collect data from this app?» ответь **No**.

Это правда: приложение не собирает ничего, всё хранится на устройстве.

---

## Шаг 7. Экспортное соответствие

При отправке спросят про шифрование. Ответы:

| Вопрос | Ответ |
|---|---|
| Does your app use encryption? | **Yes** |
| Does it qualify for exemptions? | **Yes** |
| Does it implement proprietary encryption? | **No** |

Приложение использует только стандартные протоколы (TLS и открытые
VPN-протоколы), поэтому попадает под освобождение.

## Шаг 8. Примечания для ревьюера

Это самый важный пункт для VPN-приложения. Текст — в `review-notes.md`.

**Обязательно приложи рабочий ключ или подписку** в поле Notes, иначе
ревьюер не сможет проверить приложение и отклонит его.

**Add for Review** → **Submit to App Review**

Ожидание обычно 1–3 дня.

## Чего ждать

VPN-приложения проверяют строже обычных. Частые причины отклонения:

- **Нет политики конфиденциальности** или ссылка не открывается
- **Ревьюер не смог подключиться** — не дали тестовый ключ
- **Guideline 5.4** — требуют подтвердить, что ты имеешь право предоставлять
  VPN-сервис и что приложение не собирает данные пользователей. Ответ на это
  есть в `review-notes.md`
- **Приложение выглядит как оболочка** для чужого сервиса без собственной
  ценности

Если отклонят — это нормально и поправимо. Пришли текст отказа, разберём.
